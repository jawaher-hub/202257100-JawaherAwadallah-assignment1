# Personal Portfolio - Jawaher Awadallah

## Project Description
A responsive personal portfolio website showcasing my journey as a junior Computer Science student and an aspiring Cybersecurity Specialist. This project highlights my technical skills in system design, UI/UX prototyping.

## Key Features
* **Responsive Design:** Fully functional layout across desktop, tablet, and mobile devices using CSS Flexbox.
* **Dark/Light Mode:** A custom theme toggle for improved user experience.
* **Smooth Scrolling:** Fluid navigation between sections via internal anchor links.
